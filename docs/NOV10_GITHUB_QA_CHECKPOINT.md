# Beta 0.3.4 (21) — QA source checkpoint, not a release

The code on this branch is a source checkpoint. It does **not** turn on the new matching route for users. The ordinary build flags and the private phone flags differ: the installed preview pointed at an isolated QA service, with interpreted matching on, public OpenAI off and checkout off. On 10 November the actual service separately reported that cart writes and checkout were disabled. Source publication does not deploy the backend or upload a Play build.

- The approved in-place preview update retained the existing Android install and app data. The installed APK matched SHA-256 `c366ec214dc0802b4979c127c8cd22b6fed0800f9a56abe2ae12051333127b53`. The phone passed the Swiggy connection test (HTTP 200 READY). No live grocery search, cart write, address change, order or payment was part of this checkpoint.
- Nov 10 focused local Android catalogue/ingredient/reported-order suite **75/76**; only `SwiggyReportedBasketRegressionTest.exposedStandardMilkChocolatePopcorn` failed. Latest broad local suite from Nov 9: 2,535 passed, 39 skipped, 1 known failure. Backend had 559 focused passes on Nov 10. The physical phone used the private QA revision, not a new deployment of the latest backend changes.
- The most recent genuinely new blind test had **0/12 basic and 0/3 long complete stocked baskets** for each of the two scored providers. No stocked basket reached search. One October repeated live list did reach a correct 5/5 review. Neither a successful connection nor a large unit-test count is a usability percentage.
- The source snapshot includes the application code and selected regression tests and supporting contract fixtures. It intentionally does not include private phone data, signing material, binaries, historical experiment branches, or unpublished evaluation panels. A local full-suite count is not the number of tests redistributed in the public checkpoint.

The companion [backend source checkpoint](https://github.com/gandharvbakshi/beta_backend/commit/3dc2e2c90c06f82151c2e6fa1de6ec65c31e6b36) passed the focused 559-test run with external network connections blocked; all 39 root-level source/fixture files actually read matched the staged Git contents. Android application sources match the working preview source; the exact checkpoint unit-test and device-test Kotlin source sets compiled (172 and 37 files, respectively).

The published Android unit-test source set was also run locally in full: **2,330 passed, 2 skipped, 1 failed** (2,333 total). The same milk/carton regression is the only red test. Do not interpret this as 2,330 completed grocery orders.
